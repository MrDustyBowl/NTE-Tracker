# NTE Tracker v1.2.2 — Small roster icons

Cette mise à jour remplace les petites icônes de la liste des personnages par les nouvelles vignettes rondes fournies.

## Fichiers inclus
- `src/main.js`
- `src/assets/roster-icons/*.png`
- `index.html`
- `scripts/prepare-v1.2.2.cjs`

## Publication
Depuis la racine du dépôt :

```powershell
node scripts/prepare-v1.2.2.cjs
```

Puis commit/push, laisse GitHub publier, et installe depuis `Check Updates`.
