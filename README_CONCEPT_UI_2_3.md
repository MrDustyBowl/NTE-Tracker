# NTE Tracker 2.3 — Neon Dossier

An extensive visual rebuild of the user's concept screenshot, preserving the backend.

The three-column Characters dashboard has a roster on the left, portrait + skills in the center,
and team, awakening, bond and owned arcs on the right. Pink magazine-like display typography,
dark surfaces, graffiti backgrounds, jewel-like skill placeholders and responsive layout.

All numeric values are taken from the user progress/catalogue; no character HP/ATK or
skill descriptions have been invented. Skill icons and hero artwork deliberately remain placeholders
until vetted asset batches are available. Toggle favourites and assign/unequip from the four
team slots: both save to existing SQLite character progress without migrations.

Global catalogue, owned-art sync, updater, backups and other tabs still work.
Version 2.3.0. Signed releases remain manual.
